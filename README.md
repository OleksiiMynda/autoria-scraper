# AUTO.RIA Web Scraper (Playwright) 

Скрипт мовою Python для автоматизованого збору даних з популярного українського маркетплейсу автомобілів AUTO.RIA. 

##  Технології
- **Python 3**
- **Playwright** (для роботи з динамічним контентом та JavaScript)
- **CSV** (для експорту даних)

##  Що робить скрипт:
1. Запускає браузер та переходить на сторінку пошуку авто.
2. Чекає повного завантаження JavaScript-елементів (очікування рендеру).
3. Збирає дані: Марка/Модель, Ціна, Пробіг, Посилання.
4. Зберігає всі дані у структурований файл `cars_data.csv`.

Цей скрипт демонструє вміння працювати з динамічними сайтами, обходити базові блокування та структурувати "сирі" дані для клієнта.
